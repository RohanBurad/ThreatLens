🛡️ About ThreatLens

ThreatLens was built as part of a 15-day IBM CSRBOX Cybersecurity Internship. The goal was to create a tool that doesn't just detect phishing URLs — but explains why a URL is dangerous, making it educational for both security professionals and everyday users.

The tool uses Python Flask as the backend, analyzes 15+ heuristic signals, validates SSL certificates in real time, and checks domain registration age via WHOIS — all without relying on paid APIs.

Internship Timeline
Days 1–3 — URL parsing, feature extraction, heuristic engine
Days 4–6 — SSL validation, WHOIS integration, risk scoring
Days 7–10 — Flask web app, PDF report generator, UI design
Days 11–13 — Multi-page UI, dark/light mode, testing & documentation
